I'm deploying 8 patched source files + 1 one-off SQL migration that improve follow-up email quality substantially.

The core architectural change: the follow-up LLM now receives the FULL original email body (not just a 5-12 word summary) so it can reference specific facts. This requires adding one new column to the prospects table.

Secondary fixes in this bundle: prospect name is now parsed from the email's opening greeting ("Hi Jesaja," → Jesaja) instead of the Gmail header (which often contained the recipient's email local-part). Free-mail domains (gmail.com, yahoo.com, etc.) no longer become fake company names. And the Follow-ups page now has a 3-dots menu → modal that shows the original email each follow-up chain is based on.
